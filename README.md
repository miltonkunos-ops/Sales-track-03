# Sales Track PWA

A fast, offline-first Progressive Web Application (PWA) for managing point-of-sale operations, inventory tracking, financial ledgers, audit logging, and user access control.

## Features
- **Role-Based Access Control**: Separate permissions for Administrators and Employees.
- **Offline First**: Runs completely offline via LocalStorage and Service Workers.
- **SHA-256 Authentication**: Passwords hashed locally using Web Crypto API.
- **Thermal Receipt Printing**: Instant print trigger integration via RawBT.
- **Audit Logging**: Comprehensive system activity logs.
- **Real-time Live Sync**: Firebase Firestore integration for multi-device sync.

## Deployment
